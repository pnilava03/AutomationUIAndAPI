# UI + API Automation Framework (Selenium + Rest Assured)
Scalable automation framework supporting UI and API testing using Selenium WebDriver, Java, TestNG, Cucumber BDD, and Rest Assured.

## Features

- UI automation using Selenium WebDriver
- API automation using Rest Assured
- Page Object Model design
- TestNG + Cucumber support
- Reusable utilities
- CI/CD ready framework
- Clean project architecture

**Prerequisites**
**Make sure you have installed:**
Java 11+
Maven
Chrome browser
IDE (IntelliJ / Eclipse)

## Quick Start

**Clone repo:**
git clone https://github.com/pnilava03/AutomationUIAndAPI.git

**Run tests:**
mvn test

**Run smoke suite**
mvn test -Dsurefire.suiteXmlFiles=src/test/resources/xmlFiles/smoke.xml


## Why This Framework
- Scalable architecture
- Supports UI + API in single project
- Easy to maintain
